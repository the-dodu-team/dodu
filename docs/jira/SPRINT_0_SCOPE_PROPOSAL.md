작성: 2026-09-22. 사용자 제공 가용 시간은 각자 하루 1~2시간입니다.
현재 세션에서 Jira 도구와 제어 가능한 브라우저가 없어 Sprint 0의 실제 ID·기간·소속 티켓·진행 상태를 확인하지 못했습니다.
이 문서는 기존 로컬 명세와 이전 등록 기록에 근거한 후보이며 Jira 변경 완료 기록이 아닙니다.

## 산정 기준

- 금요일 9월 25일까지 화~금 4일을 모두 사용할 경우 1인당 4~8시간입니다. 오늘 이미 사용한 시간·휴일은 추가 차감하며 주말 근무는 가정하지 않습니다.
- 최소 4시간 중 최대 3시간을 주 작업, 1시간을 리뷰·수정 여유로 배정합니다. 8시간 가능한 사람에게만 추가 작업을 넣습니다.
- ChatGPT는 초안·예제·오류 분석을 지원한다고 가정합니다. 실행·통합·팀원 검토·정책 승인 시간은 생략하거나 자동 단축하지 않습니다.
- FE는 기존 초보 숙련도를 유지하며 중급자로 재분류하지 않습니다. mono의 FE 지원도 가용 시간에서 차감합니다.
- 아래 시간은 완료 보장이 아닌 잔여 작업의 계획 범위입니다. 이미 완료되었거나 상당히 진행된 경우 재산정합니다.

## Jira 접근 복구 후 적용 절차

1. 보드 2의 Sprint 0 ID·시작/종료일·실제 전체 티켓과 하위 작업을 조회합니다.
2. 담당자·완료 기준·현재 진행률·차단 관계를 위 후보와 비교합니다. 여기에 없는 신규 티켓도 같은 기준으로 산정합니다.
3. 완료된 티켓은 유지합니다. 진행 중인 티켓은 잔여 범위로 재산정하고 기존 완료 실적을 제거하지 않습니다.
4. 미착수이고 가용 시간·선행 조건을 충족하지 못하는 티켓만 백로그로 이동합니다. 티켓을 삭제하거나 임의로 다음 Sprint를 만들지 않습니다.
5. 담당자별 총시간과 교차 리뷰 시간을 다시 합산합니다. 특정 날짜의 완료를 보장하는 Due date는 임의 설정하지 않습니다.
6. 변경한 티켓을 재조회해 Sprint 제외 여부를 검증하고 유지·이월 목록과 이유를 이 문서에 실제 키로 기록합니다.

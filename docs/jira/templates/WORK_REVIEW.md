# 작업 결과 확인 양식

Jira 또는 PR 본문에 복사해 사용합니다. 확인하지 않은 항목은 체크하지 않습니다.

## 담당자 작성

- Jira / 상위 티켓:
- 담당자 / 검토자 / 인수 담당(해당 시):
- PR·결과물 링크 / 커밋:
- Decisions.md 기록 ID:
- 완료한 범위 / 제외한 범위:
- 확인 방법: 준비 환경 → 실행 명령·조작 → 기대 결과.
- 실제 검증 결과 / 미실행과 이유:
- 화면·실행 로그·fixture 등 증거: 비밀값과 실제 참가자 데이터 제외.
- 관련 OPEN ID / 막힌 사항:

## 검토자 작성

- 확인자 / 확인 일시 / 실제 검토 커밋:
- 판정: 미확인 / 수정 필요 / 확인 완료
- 확인한 결과와 재현 기록:
- 필수 수정 / 제안 / 질문:
- 인수 담당 확인(해당 시):
- 남은 작업과 연결 티켓:

## 완료 전 확인

- [ ] 원래 완료 기준을 충족했습니다.
- [ ] 담당자 외 검토자가 결과물을 확인했습니다.
- [ ] 코드·문서 변경 PR이 dev에 병합됐습니다. PR 없는 조사라면 최종 결과 링크와 확인 근거를 남겼습니다.
- [ ] OPEN 제안을 승인된 정책으로 취급하지 않았습니다.
- [ ] 최종 결과와 확인 기록을 Jira에서 찾을 수 있습니다.

AI 리뷰·CI 성공만으로 사람의 검토나 제품 정책 승인을 대신하지 않습니다.

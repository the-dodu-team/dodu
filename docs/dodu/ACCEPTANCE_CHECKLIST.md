# 구현 수용 기준 및 QA 시나리오

상태: 실행 전 체크리스트. 체크되지 않은 항목은 검증 통과를 의미하지 않는다.
D01~D13 최종 결정문과 LOCKED 기준을 검증한다. 체크되지 않은 항목은 검증 통과를 의미하지 않는다.

## 예약과 시간
- [ ] 저장 시 서버 기준 +5분/+72시간 경계 직전·정확한 경계·직후를 검증한다.
- [ ] 활성 약속 1개와 동일 예정 시작일(KST) 1개 제한을 동시 요청에서도 유지한다.
- [ ] 시작 전 취소 후 동일 최종 예정 시작일 KST 날짜 재생성은 최대 1회 허용하고 세 번째 약속은 거절한다.
- [ ] 시작 전 수정 1회만 허용하고 수정 시점 예약 조건을 다시 적용한다.
- [ ] T 이후 수정·취소 요청을 서버에서 거절한다.
- [ ] 수정 후 이전 시간의 알림·만료 작업이 새 상태를 변경하지 않는다.
- [ ] 날짜 이동은 자동 취소+재생성이 아닌 동일 약속 수정 1회로 기록한다.
- [ ] TechFailed 후 동일 날짜 기술복구 재예약은 사용자 재생성과 별도로 최대 1회 허용한다.
- [ ] 공식 종료 후 신규 약속·수정·재생성·기술복구·알림·인증을 차단하고, 종료 전 접수 제출과 개별 자기보고는 완료할 수 있다.
- [ ] 공식 종료 경계와 마지막 자기보고는 D03/D11에 맞춰 검증한다.

## 알림·사진·상태
- [ ] T / T+10 / T+20 일정이 적용되고 성공 후 재알림이 발송되지 않는다.
- [ ] 직접 진입 및 알림 진입 모두 동일한 인증 창을 사용한다.
- [ ] 서버가 마감 전 접수한 유효 사진은 판정이 늦어져도 기다린다.
- [ ] 사진 제출은 `T ≤ server_received_at < T+30`을 적용한다. 정확히 T는 허용하고 정확히 T+30은 신규 제출을 거절한다.
- [ ] 마감 후 도착한 성공은 정상 접수된 해당 시도에 귀속한다.
- [ ] 마감 후 거절은 추가 제출 없이 인증 미완료 종료한다.
- [ ] 판정 대기 중 창 만료가 최종 인증 미완료를 먼저 확정하지 않는다.
- [ ] 시간 내 거절 후 재제출이 가능하고 임의의 사용자 횟수 제한이 없다.
- [ ] 약속당 동시 Evaluating 사진을 최대 1개로 제한하고 Evaluating 중 추가 제출을 거절한다.
- [ ] 중복 제출/콜백·역순 결과·중복 스케줄 실행은 D08/D10의 멱등·최종상태 규칙을 보존한다.
- [ ] 권한 거부는 판정거절/기술오류와 별도로 기록한다.
- [ ] 기술 실패는 인증 완료·미완료 집계에 들어가지 않는다.
- [ ] 오류 복구 중 마감 경과는 D04 결정대로 처리한다.
- [ ] 브라우저 종료·재진입으로 시간이나 완료 결과가 초기화되지 않는다.

## 자기보고·기록
- [ ] 미인증 시작자/시작 후 인증자도 D01 기준으로 정확히 응답할 수 있다.
- [ ] 자기보고는 최종 인증 결과를 변경하지 않는다.
- [ ] 안내는 비강제이며 건너뛰기 후 새 약속 생성이 가능하다.
- [ ] 최종 T 기준 18:00/다음날 11:00 최초 안내, Push 1회, 24시간 내 인앱 재안내 1회, 24시간 만료를 검증한다.
- [ ] 설문 대상은 AuthCompleted/AuthIncomplete만 허용하고, Cancelled/TechFailed/권한 문제/Withdrawn에는 새 수집·알림이 없다.
- [ ] 인증 미완료와 자기보고 미응답/미시작을 구분한다.
- [ ] 실제 작업 시작 여부·시작 순서·인증 후 시작 지연 구간을 인증 결과와 별도로 저장한다.
- [ ] 사용자 화면에 ‘약속 성공/실패’, ‘시작 성공률’, ‘작업 수행률’을 인증 지표로 표시하지 않는다.
- [ ] 집계 분모에서 취소·기술 실패를 제외하고 철회·권한 영향은 분석 기준에 따라 분리한다.

## 로그·운영
- [ ] 사진 제출·결과·오류를 약속 및 시도별로 연결한다.
- [ ] 재전송 로그를 중복 집계하지 않는다.
- [ ] 알림 발송만으로 사용자 수신·열람을 기록하지 않는다.
- [ ] 반복 생성 지표의 날짜 기준과 정책/모델 버전을 명시한다.
- [ ] 서로 다른 최종 예정 시작일의 새 약속만 반복 생성으로 집계하고, 동일 날짜 재생성·기술복구는 제외한다.
- [ ] 반복 개입 도달은 약속이 취소되지 않고 최종 T까지 도달한 경우로 별도 집계한다.
- [ ] 참가자별 데이터 접근을 분리하고 접근정보 재발급 시 기존 접근정보가 무효화된다.
- [ ] 철회 시 예약 개입·수집·접근을 중단하고 늦은 비동기 결과를 행동 결과에 반영하지 않는다.
- [ ] 사진 30일/연결 원시 데이터 90일 보관 한도 및 삭제 요청을 반영한다.
- [ ] 삭제 요청 대상에 사진·원시 이벤트·개별 설문·식별 연결이 포함된다.
- [ ] 실제 지원 기기에서 알림·촬영·업로드·상태 복원을 확인한다.
- [ ] 실제 환경 샘플로 AI QA를 수행하고 모델 버전과 결과를 기록한다.
- [ ] D13 결과를 Go/부분 Go/판단 보류/No-go로 기록하고 로그·자기보고·인터뷰·AI/환경 QA 근거를 함께 남긴다.

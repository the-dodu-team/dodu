# Notion 요구사항 동기화 — 2026-10-13

상태: 최신 원문과 병합 산출물의 구현 영향 기록. 제품 정책 원문을 대체하지 않는다.

## 근거와 확인 범위

- [서비스 운영 정책](https://app.notion.com/p/3e780115466280188446daadeb64a950)의 MD 업데이트 기록에서 `Service_Operation_Policy_v2.5_Baseline_LOCKED_20261013_UPDATED.md`를 직접 읽었다.
- 최신 첨부 §1.3은 **작업명 최대 30자** 입력 정책이다. 페이지 본문은 아직 §1.3이 없어 첨부와 불일치한다. 이전 대화의 20자 및 개발 제안 50자를 적용하지 않는다.
- 최신 첨부에서 최근 작업명 5개·로컬 목록 정책은 확인되지 않았다. 이전 이미지와 대화만으로 현재 확정 범위에 추가하지 않는다.
- PRD·Flow/State/Log 최종 페이지도 조회했다. 이 두 페이지에는 작업명 신규 정책의 동기화 내용이 확인되지 않았다.
- 지정 기준 페이지 `3d64c293890d80cc940bdc3cef7aa32c`는 404다. 해당 페이지와 그 하위 항목 전체의 최신 확인을 완료했다고 주장하지 않는다. 검색으로 발견한 접근 가능한 최종 문서 범위만 확인했다.

## 승인된 입력 정책과 미확정 구현 계약

최신 LOCKED 첨부 §1.3: 최대 30자 단일 행, 일반 문자·기호 허용, 줄바꿈·제어문자 불허, 저장 시 앞뒤 불필요한 공백 제거, 제거 후 빈 값이면 다음 단계 진행 불가. 30자는 MVP 초기 운영값이며 임의 조정하지 않는다.

FE와 서버가 같은 기준으로 검증한다. 글자 계산(이모지/조합 문자), trim 대상 문자, 제어문자 범위는 원문에 구체화되지 않아 기술 계약이 필요하다. 최근 목록의 동일 문자열 판단은 해당 기능이 현재 범위인지 확인 후 별도로 결정한다.

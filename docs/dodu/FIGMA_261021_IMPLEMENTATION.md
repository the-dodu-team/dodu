## 동작 연결

- 신규 참가자는 온보딩을 닫아 홈으로 건너뛰지 않는다. 현재 구독 해제 후 입장 화면으로 돌아간다.
- 설정에서 알림 허용 시 카메라 단계로 이동한다. 실제 영상 권한을 확인한 직후 모든 트랙을 종료한다. 완료는 서버 저장 성공 후 홈으로 이동한다.
- `PUT /api/participant/onboarding`은 최초 완료 시각을 보존하며 세션 교체·철회·만료를 저장 시 다시 확인한다. 완료 이력은 브라우저 권한이나 Push 구독 완료 증거가 아니다.
- 로그아웃은 현재 세션의 구독 해제 성공 후 로컬 토큰을 지운다. 이미 무효인 세션의 401은 로컬 정리를 허용한다. 계정 철회·참가자 삭제 API는 호출하지 않는다.
- 사진 신규 제출은 서버 시각 기준 `T ≤ now < T+30`. 접수된 판정은 마감 후에도 기다린다. 기술 종료는 인증 미완료와 분리하고 존재하지 않는 복구 기능을 표시하지 않는다.
- 자기보고 저장 결과가 불명확하면 상태 확인 화면 하나만 표시한다. 닫기는 건너뛰기 제출이 아니다.

## 검증

- `npm run verify`: 비밀값 검사, FE 테스트·lint·빌드, Docker/PostgreSQL 통합 검증 포함 BE **251건** 통과, 실패·오류·건너뛰기 0. lint는 오류 없이 경고가 남아 있다.
- 후속 FE 수정 후 `npm run test:integration-ui --workspace frontend`: **33건** 통과. 마감 후 판정 대기·기술 종료 분리·인증된 완료/구독 해제 경로 추가 검증.
- DB: 재입장 시 온보딩 완료 유지·최초 완료 시각 보존, 교체 세션·철회·접근 만료 시 저장 거절.
- 합성 API Chrome: 카메라 거부 후 허용·트랙 종료, 완료 저장 실패 후 재시도·새로고침 복원, 사진 압축·1회 제출·polling 완료, 로그아웃 취소·실패 후 재시도, 이력 5→8건, 320/375/430px 가로 넘침 없음·JS 오류 0.
- 로컬 스크린샷으로 컴퓨터 촬영 안내·성공·설정·로그아웃·기록 확인. 실제 참가자 사진·코드·토큰은 테스트나 저장소에 포함하지 않는다.

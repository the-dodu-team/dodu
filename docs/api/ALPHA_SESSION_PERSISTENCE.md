# 알파 웹 세션 유지

- 2026-11-11 사용자 승인: 알파 기간에는 서버 발급 세션 토큰만 localStorage에 보관한다. 참가자 코드 원문은 보관하지 않는다.
- 서버의 세션 만료·철회·기기 전환·참가자 소유권 검증은 유지한다. 클라이언트 저장은 접근 권한을 부여하지 않는다.
- 기존 sessionStorage 토큰은 한 번만 이전한다. 로그아웃 후 다른 탭의 오래된 토큰을 다시 이전하지 않는다. 미확정 쓰기 요청은 기존 탭에만 보관한다.
- OS·브라우저가 홈 화면 앱 삭제 시 사이트 데이터를 삭제하면 자동 로그인은 복원할 수 없다. 이 경우 유효한 코드로 재입장해 서버의 기존 약속·이력을 조회한다. 설치마다 참가자를 새로 생성하지 않는다.
- 사용자는 최초 로그인 실패 신고에 대해 별도 오류 문구가 없고 로그인 실패는 아닌 것으로 정정했다. 실제 실패 원인은 확정하지 않는다.
- localStorage 토큰은 자바스크립트 접근 및 XSS 탈취 위험이 있다. 알파 이후 웹 HttpOnly Cookie 검토, Sprint 6 RN 보안 저장소 전환이 남아 있다.

검증: 플랫폼 세션 테스트, 프런트 빌드, 합성 API Chrome 재입장·기기 변경 테스트 통과. 재입장 테스트는 창 닫기·새 창 복원, 저장소 삭제 후 코드 입장·기존 약속 복원을 포함한다. 실제 모바일 앱 제거·재설치 및 운영 DB 테스트는 미실행. 백엔드 미변경으로 전체 백엔드 테스트는 재실행하지 않았다.

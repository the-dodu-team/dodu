# 약속 생성 시간 입력

- 기본 시각: 화면 초기화 시 현재 시각 +6분에서 초를 제외한 시·분.
- 예: 12:32:01 → 12:38, 23:58:59 → 다음 날 00:04.
- 날짜는 자동 설정된 값을 읽기 전용으로 표시하며 시간은 분 단위로 수정할 수 있다.
- 기존 시작 시간 상자 안에 time 입력을 배치하며 별도 입력 상자는 추가하지 않는다. 생성·수정 화면 모두 시간 휠은 표시하지 않는다. 기존 휠 구현은 비활성 상태로 보존한다. 생성 화면의 날짜 칩은 변경 불가로 표시한다.
- 뒤로 이동한 경우 유효한 이전 선택을 보존한다. 최소 예약 시각에 미달하면 기본값을 다시 계산한다.
- 시간 변경은 날짜를 임의 변경하지 않는다. 선택한 날짜에서 유효하지 않은 시간은 안내하고 제출하지 않는다.
- 서버의 최소 +5분·최대 +72시간·개입 종료 경계는 유지한다. 기존 약속 수정 화면은 기존 날짜·시간 선택 방식 유지.
- 검증: `node frontend/tests/home-history.test.cjs`, `npm run build --workspace frontend`.
